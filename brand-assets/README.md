# Home Assistant brand icons

These PNG files are integration brand icons for Home Assistant 2026.3 and
newer. Each component uses its icon from a `brand/icon.png` file.

The icons for integrations maintained in this repository are included in
their component folders:

- `custom_components/hitokoto/brand/icon.png`
- `custom_components/oxidns/brand/icon.png`
- `custom_components/sirivision_switch/brand/icon.png`

The WxPusher integration is maintained outside this repository. Copy
`brand-assets/wxpusher_simple/icon.png` to
`/config/custom_components/wxpusher_simple/brand/icon.png` in Home Assistant.
