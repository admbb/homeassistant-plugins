# Contributing

1. Open an issue for a bug or feature proposal.
2. Keep changes inside the single `custom_components/hitokoto` integration and its tests.
3. Add or update tests for behavior changes.
4. Run `uv run ruff check .`, `uv run ruff format --check .`, and `uv run pytest`.
5. Include Home Assistant logs with private information removed when reporting setup problems.

Please do not add API keys, personal data, history exports, or favorite lists to issues or pull requests.
